The pairing code — and the reason you cannot have one — now appears directly under the button that asked for it. Both used to render below the help paragraphs, usually under the settings window's fold, so pressing "Show pairing code" on a LAN browser looked like nothing happened while the answer ("making another owner is done on the box, or after the house password is on") sat unseen further down, styled like help text. Refusals are now red and the window scrolls the result into view.
